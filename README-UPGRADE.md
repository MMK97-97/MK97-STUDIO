# MK97 Creative Studio — App UI v2.0

This package upgrades only the MK97 app shell to a CapCut-inspired workflow while keeping the MK97 brand and your existing editor engines.

## Keep these existing files/folders from your live website
- `poster-editor.html`
- `video-editor.html`
- `assets/` (especially `assets/MK97.png`)
- all editor JavaScript/CSS/media/template assets already used by those editors

## Add/replace from this package
- `index.html`
- `templates.html`
- `projects.html`
- `tools.html`
- `poster.html`
- `video.html`
- `library.html`
- `more.html`
- `mk97-app.css`
- `mk97-app.js`
- `manifest.webmanifest`
- `sw.js`

Home · Templates · Create · Projects · Tools

The central Create button opens Video Project, Poster Design, Upload Media and Use Template actions.
